# Provenance and distribution scope

This pack is newly worded procedural distillation from a local default-profile skill-library audit. It is not a mirror of an upstream collection. The original library mixes imported material, generated consolidation outlines, local operational lessons and private context; it cannot safely be assigned a blanket license or published wholesale.

## Source families and replacements

| Local source family | Portable replacement |
| --- | --- |
| Software development lifecycle, planning, test-health workflows | scoped-implementation |
| Lifecycle debugging and measure-before-you-fix | evidence-first-debugging |
| Code review and lifecycle verification | risk-based-code-review |
| GitHub workflow umbrella and CI evidence guidance | verified-github-delivery |
| Subagent development and autonomous-agent operations | bounded-agent-delegation |
| Self-hosted service and local-systems operations | safe-service-operations |
| Agent knowledge/skill governance | portable-skill-audit |

The source families provide design provenance, not upstream endorsement. Original packages, support scripts, personal records, credentials, sessions, hidden archives, plugins and other profiles are not exported. Some source packages have licenses in metadata; those declarations were not used as permission to relicense the whole library.

The publication improves selected coding-agent workflows. It does **not** claim that every audited package was rewritten or repaired. The live library remains in place; only a narrow backed-up safety patch was applied there. Future exports should be reviewed individually, including all support files and applicable notices.
